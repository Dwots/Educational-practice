Этот проект это верстка сайта в котором присутствует обучающий материал по физике на тему "Электрический ток" со scorm тестом.

Сделан как SCORM 1.2 пакет: три страницы с теорией и тест на 8 вопросов (есть вопросы с одним и с несколькими ответами). После теста считается процент правильных ответов, от 70% ставится `passed`, ниже — `failed`. Балл и статус отправляются в LMS через `cmi.core.score.raw` и `cmi.core.lesson_status`. Для связи с LMS используется pipwerks SCORM wrapper.

## Как запустить

Заархивировать содержимое папки в zip так, чтобы `imsmanifest.xml` лежал в корне архива, и загрузить в любую LMS с поддержкой SCORM 1.2, например в мою [Scoreme](https://github.com/Dwots/Scoreme).

Страницы можно открыть и просто в браузере (`pages/page_start.html`), но тогда результат теста никуда не отправится.
